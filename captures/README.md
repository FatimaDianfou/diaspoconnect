# Captures d'écran

Ce dossier doit contenir les captures des écrans principaux de l'application, à ajouter avant la remise finale :

- `01_connexion.png` — écran de connexion
- `02_membres.png` — liste des membres
- `03_membre_detail.png` — détail d'un membre
- `04_annonces.png` — liste des annonces
- `05_evenements.png` — liste des événements
- `06_profil.png` — écran de profil
- `07_devtools.png` — capture de Flutter DevTools pendant le débogage

Pour capturer un écran sur macOS : `Cmd+Shift+4` puis sélectionner la fenêtre de l'application (`flutter run -d macos` ou `flutter run -d chrome`).
